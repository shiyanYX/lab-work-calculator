# 员工属性点计算器

一个用于计算《脑叶公司》游戏中员工属性点增加的工具，支持桌面应用和网页版本。

## ✨ 功能特点

- 🧮 **核心计算**：根据工作类型、异想体危险等级、工作等级等参数计算属性点增加
- 🛡️ **E.G.O护甲系统**：支持E.G.O护甲的伤害抗性计算，影响工作伤害结果
- 🔮 **完全期望计算**：基于员工自律属性计算期望成功率、期望PE-BOX产量和期望属性点增加
- 📈 **练级期望值**：基于当前练级结果计算到下一个等级和100属性需要的次数
- 📱 **响应式设计**：支持桌面和移动设备
- 🖥️ **桌面应用**：使用 Tauri 构建的跨平台桌面应用
- 📊 **异想体数据库**：内置完整的异想体数据，包括伤害类型、伤害值和最大PE-BOX产量
- 🏅 **E.G.O护甲数据库**：内置完整的E.G.O护甲数据，包括所有等级和抗性
- ⚡ **实时计算**：输入参数后立即计算结果
- 🎨 **美观界面**：简洁现代的用户界面

## 📋 使用说明

1. **输入参数**：
   - 初始属性值
   - 工作类型（本能、洞察、沟通、压迫）
   - 异想体选择（按等级筛选）
   - 工作等级（Ⅰ-Ⅴ）
   - 工作前后的生命值和精神值
   - E.G.O护甲选择（按等级筛选）
   - 培训加成、文职加成、常驻加成

2. **期望伤害计算**：
   - 勾选「使用期望伤害计算」以基于PE-BOX数量差计算伤害
   - 勾选「完全期望计算」以基于员工自律属性计算期望结果

3. **点击计算**：
   - 点击「计算」按钮获取属性点增加结果
   - 查看练级期望值和完全期望计算结果

4. **参考数据**：
   - 右侧显示计算结果和期望值数据
